## Descrição do Projeto

> [!NOTE]
> O **Curupira** é visto como uma entidade sagrada e protetora das matas e dos animais na visão dos povos indígenas brasileiros, por isso o nome do projeto leva este nome. O projeto **Curupira** é uma página desenvolvida para uma ONG local focada na preservação da fauna e do ecossistema brasiliense, assim, estamos alinhados ao **[Objetivo de Desenvolvimento Sustentável (ODS) 15](https://brasil.un.org/pt-br/sdgs/15)** da ONU, que busca proteger, restaurar e promover o uso sustentável dos ecossistemas terrestres. O tema principal é vida silvestre. Nesta primeira etapa do projeto, conforme descrito, foi apenas utilizado HTML e CSS, sob aplicação de conceitos como: tags semânticas, modelo de caixa, flexbox, grid layout e responsividade vistos em sala de aula. O sistema como um todo possui uma página principal, cujo nome do arquivo é `index.html`, uma página de login, cujo arquivo é `login.html` e, por fim, uma página de cadastro, cujo nome é `cadastro.html`.
